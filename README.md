# Регина — портфолио

Статический сайт: главная, работы, профиль и контакты. Все изображения, шрифт и видео хранятся в репозитории.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем Save.
Для GitHub Free репозиторий должен быть публичным. Для приватного репозитория нужен подходящий платный тариф.

Первичный адрес: https://gaisinawave.github.io/portfolio/

Относительные ссылки поддерживают размещение в /portfolio/ и на собственном домене.
Домен gaireggi.ru пока не подключён: сначала проверьте публикацию, затем настройте Custom domain и DNS.

## Локальная проверка

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/ . Сборка не требуется.
